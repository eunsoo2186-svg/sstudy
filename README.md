# 📊 sstudy - AI 기반 주식 종합분석 플랫폼

> 초보 투자자를 위한 **원-클릭 기업분석 & 지능형 학습 시스템**

## 🎯 프로젝트 개요

기업명 하나만 입력하면 **투자 의사결정에 필요한 모든 정보**를 종합적으로 제공:

- ✅ **종합 기업분석** - 핫한 이유, 섹터, 밸류에이션, 경쟁우위, 리스크
- ✅ **스마트 학습노트** - 개념 자동 연결, 복습 스케줄, 지식 그래프
- ✅ **인터랙티브 차트** - 이벤트 오버레이, 매크로 지표 매핑
- ✅ **매크로 매핑** - 섹터별 주요 지표 및 영향도 분석

## 🚀 핵심 기능

### 1. ONE-CLICK 기업분석 대시보드
```
입력: 기업명 (예: SK하이닉스)
↓
출력:
├─ 기본정보 (PER, PBR, PEG, ROE, ROA, 배당률)
├─ 섹터분류 (대/중/소/세분류)
├─ 핫한이유분석 (5가지 신호)
│  ├─ 밸류에이션 시그널
│  ├─ 내부자거래 시그널
│  ├─ 기술혁신 시그널
│  ├─ 펀더멘탈 시그널
│  └─ 뉴스/이벤트 시그널
├─ 고평가/저평가 판정
├─ 가격변화 원인분석
├─ 경쟁사 벤치마킹
├─ BULL/BEAR 시나리오
├─ 진입타이밍 판단
└─ 매크로 영향도 매트릭스
```

### 2. 스마트 학습노트
- 📝 템플릿 기반 학습 (5단계 체크리스트)
- 🔗 자동 개념 연결 (지식 그래프)
- 📅 복습 스케줄 (간격반복학습)
- 🎯 개념별 실제 사례 추천

### 3. 인터랙티브 차트
- 📊 6개월 일봉 + 이벤트 마킹
- 🖱️ 호버 시 상세정보 팝업
- 📈 매크로 지표 오버레이
- 🔍 섹터별 기술지표 비교

### 4. 매크로 분석
- 🌍 섹터별 KEY 지표 선별 제시
- 📊 지수/비율로 정량화된 영향도
- 💡 맥락있는 해석문 제공

## 🛠️ 기술 스택

### Frontend
- React 18 + TypeScript
- TradingView Lightweight Charts
- Tailwind CSS + shadcn/ui
- TanStack Query

### Backend
- Node.js/Bun + Hono
- PostgreSQL + Redis
- Bull (Task Queue)
- Claude API (AI분석)

### Data Sources
- 한국거래소 OpenAPI
- 네이버금융 (크롤링)
- 한국은행 API
- News API + RSS
